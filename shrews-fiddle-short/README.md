# DAY 1 · #3: The shrew's fiddle (30 s daily-facts Short)

The script is the user's, verbatim, read by the natural Kokoro narrator (`am_michael`). The art is original cel animation:
- two townswomen bicker in a timber-framed square
- the shrew's fiddle (*Halsgeige*, "neck violin") slams in
- the double fiddle locks them face to face while the crowd laughs
- they make up, a heart appears, and the lock opens
- end card: the device on a museum wall

Labels: HISTORY (Wikipedia citing Rublack's *The Crimes of Women in Early Modern Germany*, and Britannica). The "released when resolved"
detail is tagged REPORTED because it mostly appears in secondary sources. The score is an original lute and recorder tune, with synthesized crowd, bickering, wood and lock SFX.

```bash
npm ci && npm run audio && npm run render   # -> out/shrews-fiddle-short.mp4
```
