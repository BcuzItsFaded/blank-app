# DAY 1: Octopuses have three hearts (30 s daily-facts Short)

This was built with the `shorts-studio` skill. It renders a 1080×1920, 30 fps, 30 s video using the user's script verbatim.
The art is an original cel octopus with an X-ray view of its two gill (branchial) hearts and one body (systemic) heart.
It shows the blood flowing to the gills and the body, and the blood turning blue on "blue", from copper-based hemocyanin.
The narrator is free Piper TTS (`en_US-ryan-high`). The score is an original marimba groove, and the SFX are synthesized.
Audio is mastered to about −15 LUFS / −1.5 dBTP.

```bash
npm ci && npm run audio && npm run render   # -> out/octopus-three-hearts-short.mp4
```
