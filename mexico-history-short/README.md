# Mexico's history sounds made up — but it's real (30 s facts Short)

The script is the user's, verbatim, with the citation markers removed. It's read by Kokoro `am_michael`, fitted to exactly 30 s at about 1.26× speed.
The art is original cel animation (no real-person likeness):
- papel picado and a "100% REAL" stamp
- an original-design president in a tricolour sash, a stopwatch racing to ~45 min, the 1913 date and a lunch-break sandwich
- a cacao pod splitting into stacked "coin" beans, then a cup of hot chocolate swallowing the savings
- an Egyptian pyramid crossed out, then an X-ray of the Cholula hill showing the pyramid under the yellow church, with Popocatépetl behind
- a recap of the three icons with confetti

The music is an original festive guitar-and-marimba score.

Sources (from the user): Guinness World Records (shortest presidency), Cornell Library "When Money Grew on Trees",
Wikipedia (Great Pyramid of Cholula, Pedro Lascuráin), NYT 1952, Mental Floss.

```bash
npm ci && npm run audio && npm run render   # -> out/mexico-history-short.mp4
```
