12 scenes × 5 seconds = **60 seconds**; vertical **1080×1920**, **30 fps** (**1,800 frames**) in dark hand-drawn 1990s Japanese anime horror. Small upper-left **DON'T SPOIL IT RG** brand mark. No LEGO. No hosts.

1. Upload this ZIP into Claude (preferably Claude Code if you want editable project files).
2. Paste `PASTE_THIS_INTO_CLAUDE.md` as the instruction, or use `ALL_IN_ONE_CLAUDE_PROMPT.md` by itself.

This pack contains **script, prompts, subtitles and production metadata**, not a finished rendered video, 12 image files, or generated audio. It is for animating with tools available in Claude or elsewhere. It is a trailer-based preview, not a plot-ending recap.
