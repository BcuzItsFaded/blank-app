  1. Put storyboard.png (and voice.mp3 if you have one) in the-wish/assets/, or click Download project.js below and save it into the-wish/assets/.

  3. Sources → + → Browser → Local file → the-wish/index.html; Width 1080, Height 1920; tick Control audio via OBS; custom URL params are below.
  4. Use the URL …/index.html?record=1&autoplay=3: clean frame, starts 3 s after load.
  5. Start Recording, then right-click the source → Refresh. Stop at 1:03. Trim the first 3 s.
