# T. rex lived closer to YOU than to Stegosaurus (43 s facts Short)

The script is the user's, verbatim, with no "DAY" badge. Scene lengths were set from the natural Kokoro read (narrator `am_michael`, reaction `af_heart`).
The art is original cel cartoons: a Stegosaurus in the Jurassic, a T. rex in the Cretaceous, the asteroid, and a vertical timeline
whose brackets show 77+ million years (Stegosaurus to T. rex) against 66 million years (T. rex to you).

The labels show the ranges behind the script's numbers: Stegosaurus lived about 155–145 million years ago and T. rex about 68–66 million years ago,
so the gap runs from about 145 to about 68 million years ago, roughly 77 million years.

```bash
npm ci && npm run audio && npm run render   # -> out/trex-stegosaurus-short.mp4
```
