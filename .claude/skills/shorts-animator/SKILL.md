# Shorts Animator

A script and a look in, a finished animated short out. Every frame is drawn by code you write and painted
by the GPU; nothing is generated by an image model, filmed or licensed.

```
script + look ─► short.json (lines, scenes, look, voice, music) + scenes.js (one drawing per shot)
             ─► SA frames (one painted frame per shot, you check) ─► SA render ─► <title>.mp4
                                                     ▲                                │
                                                     └──── one-sentence changes ◄─────┘
```

`SA` = `node ~/.claude/skills/shorts-animator/scripts/animate.mjs` (or this skill's `scripts/animate.mjs`).
Write the full command each time. Needs Node 22+, ffmpeg and Chrome (the doctor checks; the narrator's
Python and voice model install themselves on first use). One folder per short: `WORK=./<slug>-short`
(or `~/Desktop/<slug>-short`).

## 1. Decide — don't interrogate

Read what they gave you and decide everything yourself: the lines, how many shots, the look, the voice,
the music. Ask **one** short question only if you can't tell what the short is about. If they pasted a
script, use it word for word. If they gave a topic, write the script (`references/writing.md`): 6–14 short
lines, 20–45 seconds, one idea per line, a turn near the end, a last line that lands.

**The look is described in words, and you turn the words into a look.** Start from the closest shipped
look (`SA looks`), then override what their words ask for (`references/looks.md` maps words to numbers):

| they say | start from |
|---|---|
| oil, painterly, Van Gogh, impasto, "like the faith/Bible shorts", swirly | `oil` |
| watercolour, soft, dreamy, wash, children's book | `watercolor` |
| crayon, pastel, chalk, hand-drawn for kids | `pastel` |
| ink, comic, graphic novel, line art, manga-ish | `ink` |
| flat, storybook, gouache, minimal, calm, poster | `gouache` |

A custom look is an object: `"look": { "base": "oil", "brush": 16, "saturation": 1.3, "palette": {...} }`.
The palette (colours you choose for skies, land, people) is half of a look — pick one and keep to it.

Voice: `bm_george` (warm British man, the default for scripture and quotes), `am_michael` (American man),
`bf_emma` (British woman, stories), `af_heart` (American woman, kids). `speed` 0.85–0.95 reads calm.
Their own recording: put it in `assets/` and set `"voice": { "file": "assets/voice.m4a" }` (the lines must
match what they say, in order). `"voice": "none"` for music only. Music `mood`: `tender` (default),
`hopeful`, `night`, `wonder`, `playful`, `none`, or their own track `"assets/track.mp3"`.

## 2. Write the plan and the drawings

```bash
SA new "$WORK" --look oil
```

`short.json`:

```json
{
  "title": "Love Your Enemies",
  "format": "9:16",
  "look": "oil",
  "voice": { "id": "bm_george", "speed": 0.88 },
  "music": { "mood": "tender" },
  "lines": [
    { "say": "You have heard that it was said,", "scene": "meadow-pair", "move": "push" },
    { "say": "love your neighbour, and hate your enemy.", "scene": ["sunset-open", "lake-foliage"] },
    { "say": "Be perfect, as your Father in heaven is perfect.", "scene": ["valley-walk", "final-sky"], "transition": "fade" }
  ]
}
```

- Each line is narrated, captioned (in chunks of ≤5 words, timed to the voice) and gets one shot, or a list
  of shots that cut on its caption chunks. **Cut often: a new picture every 1.5–3 seconds** is the rhythm of
  these shorts. 12 lines → ~18 shots.
- `move`: `push` (slow zoom in, default), `pull`, `pan-left`, `pan-right`, `rise`, `fall`, `drift`, `still`.
- `transition`: `cut` (default), `fade`, `dip` (through black). Use fades rarely: the last shot, a time jump.
- `hold`: extra seconds after a line (let a big line breathe). `pause` (top level) between lines, default 0.3.
- `caption`: different words on screen than spoken; `/` forces a caption break. `captions.style`: `box`, `plain`, `none`.
- `format`: `9:16` (default), `16:9`, `1:1`, `4:5`. `fps` 24, `twos` 2 (each drawing held two frames, like
  hand animation; `1` for smooth).

`scenes.js` — one function per shot name, drawing with the kit (`references/kit.md`):

```js
window.SCENES = {
  "meadow-pair": (k) => {
    k.sky({ stops: ["#f4ecd0", "#e8dcb2"] });
    k.ground({ y: 0.6, color: "#58a531", far: "#9cc54a", stripes: 16, flowers: 90 });
    k.person({ x: 0.36, y: 0.79, h: 0.25, pose: "walk", robe: true, top: "#f3efe6", hair: "long" });
    k.person({ x: 0.62, y: 0.79, h: 0.26, pose: "walk", robe: true, top: "#1f2c6e", hair: "bun" });
  },
};
```

Draw like a painter, not like an engineer:
- **Big simple shapes, strong value contrast, one clear subject.** The paint pass adds all the texture; draw
  nothing small or fussy. Silhouettes must read at phone size.
- **Leave the caption band clear** (around 77% down) of the subject's face.
- **Every shot different**: vary the place (meadow, lake, city at night, forest, sunset, rain, interior),
  the scale (tiny figure in a big landscape ↔ two backs filling the frame), day and night, warm and cool.
- **Things move a little**: people walk (`pose: "walk"`, `dx`), water glints, clouds drift, rain falls,
  lights twinkle. Use `k.t` (seconds) and `k.p` (0→1) for your own motion.
- When the kit has no helper (a lighthouse, a boat, an animal, a cross, a car), **write it** with `k.g`
  (the 2D canvas) in a small function in scenes.js. Keep it as flat shapes in the palette.
- Match the words: "rain on the just" → rain; "the sun rise" → a sunrise; abstract lines → a symbol
  (a heart-shaped pond, a lone figure on a hill, light through trees).

## 3. Look before you render

```bash
SA frames "$WORK"     # narrates (cached), then one painted frame per shot → frames/sheet.jpg
SA still "$WORK" 7    # shot 7 full size, when one looks off
```

Open `frames/sheet.jpg`. Fix before rendering: an empty or muddy shot, a figure lost in its background
(raise the contrast or add `rim`), two shots that look alike, a caption over a face, a red "no scene" frame,
anything that doesn't match its words. Every ⚠ the command prints is a scene that threw: fix it.

## 4. Render and deliver

```bash
SA render "$WORK"     # ~1 min for 40 s → <title>.mp4 (+ renders/vN.mp4, qa/sheet.jpg)
```

Open `qa/sheet.jpg` (frames from the real file), then `open "$WORK/<title>.mp4"`. Tell them in two lines what
it is (look, length, shots) and: "Tell me what to change — one sentence is enough."

## 5. One-sentence changes

Smallest change, `SA frames`, render, show:

| they say | do |
|---|---|
| "more painterly" / "softer" / "more like watercolour" | change `look` (or its numbers: brush, swirl, wash) |
| "slower" / "faster" | `voice.speed` 0.85 / 1.0, `pause` |
| "a woman's voice" / "American" | `voice.id` |
| "no music" / "more emotional" | `music.mood` |
| "bigger captions" / "no box" | `captions.size` 52 / `captions.style` "plain" |
| "for YouTube" | `format` "16:9" (redraw shots whose layout needs it) |
| "change shot 4" | edit that scene function |

`SA set "$WORK" voice.speed=0.85` edits short.json from the shell. Every render is kept in `renders/`.

## When something goes wrong

| symptom | fix |
|---|---|
| "No Chrome found" | install Google Chrome, or `npx hyperframes browser ensure` |
| "painting on the CPU" | works, ~10× slower; on a Mac it should use Metal automatically |
| narrator install fails | it needs Python 3.10+ or `uv`; or use `"voice": "none"` / their own recording |
| a shot is solid red | its scene name isn't in scenes.js |
| voice timing off with their recording | the `say` lines must match the recording's words, in order |
