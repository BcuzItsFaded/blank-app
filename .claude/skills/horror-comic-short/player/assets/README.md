# assets/

Drop your files here. The player finds them automatically:

| File | Purpose |
|---|---|
| `storyboard.png` (or `.jpg` / `.jpeg` / `.webp`) | The combined 15-panel storyboard image for THE WISH |
| `voice.mp3` (or `.wav` / `.m4a` / `.ogg`) | Optional narration recording, aligned to start at 0:00 |
| `project.js` | Optional, from **Export → Download project.js**: your crops, timings, script, settings and embedded media |

`project.js` overrides `js/project-default.js`, field by field.
