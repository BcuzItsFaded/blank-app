# DAY 1 · #2: What if you fell into a black hole? (30 s daily-facts Short)

This was built with the `shorts-studio` skill. The script is the user's, verbatim, and "WAIT RG… WHAT?!" is read by a second reaction voice.
- **Visuals:** original cel art. A black hole with an accretion disk, an astronaut who freezes on the record scratch and then stretches into spaghettification, and an observer ship whose screen cuts to NO SIGNAL.
- **Voices:** free Piper TTS. The narrator uses ryan and the reaction uses lessac.
- **Music and sound:** an original synth score, with space SFX and a record scratch. Mastered to −14.7 LUFS.

```bash
npm ci && npm run audio && npm run render   # -> out/black-hole-short.mp4
```
